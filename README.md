# Multimodal Sarcasm Detection 🎯

This project detects sarcasm by combining:
- Text Sentiment Analysis (BERT)
- Speech Emotion Recognition (CNN)

## 🚀 Features
- Multimodal AI system
- Real-time prediction (Streamlit)
- Audio + Text analysis
- Sarcasm detection using mismatch logic

## 🧠 Models Used
- BERT (Text Sentiment)
- CNN (Audio Emotion)
- Whisper (Speech-to-Text)

## 📊 Results
- Text Model Accuracy: 97.79%
- Audio Model Accuracy: 86.14%

## 📁 Features Used
- Mel Spectrogram
- Delta Features
- Delta-Delta Features
