# Text Sentiment Analysis using BERT 

This module is part of the **Multimodal Sarcasm Detection System**, focusing on analyzing textual input to determine sentiment using a pre-trained BERT model.

---

## Overview

The text model processes input sentences and classifies them into sentiment categories:

- Positive 😊  
- Negative 😠  
- Neutral 😐  

This sentiment is later compared with audio emotion to detect sarcasm or mismatch.

---

## Model Used

- **BERT (Bidirectional Encoder Representations from Transformers)**
- Pre-trained transformer model for contextual understanding
- Fine-tuned for sentiment classification

---

## Features

- Context-aware sentiment analysis  
- Handles complex and ambiguous sentences  
- Works with real-time user input  
- High accuracy (~97.8%)
